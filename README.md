# Java Practice

A collection of small Java programs written while working through the fundamentals of the language. Each one is a standalone console exercise focused on a single concept.

This is a learning repo, not a project — the code here is meant to be read, broken, and rewritten rather than shipped.

## Structure

Files are grouped by topic, numbered in the order the concepts were covered:

```
01-basics/
02-conditionals/
03-loops/
...
```

## Running any of them

```bash
javac ProgramName.java
java ProgramName
```

The file name has to match the public class name inside it.
